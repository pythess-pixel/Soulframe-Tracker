# Soulframe Tracker

A lightweight, non-intrusive, real-time overlay tracker for Soulframe.

This tool passively parses the game's `EE.log` file to track dynamic events, such as when a procedural Arena spawns. It provides a simple click-through UI overlay that automatically resets when entering and exiting dungeons.

## Is this safe to use? (Ban Risk)
**Yes, it is 100% safe and TOS-friendly.** 

Here is why there is practically zero risk of being banned for using this tracker:
- **No Memory Injection**: The program does not inject any DLLs, read the game's RAM, or intercept network packets.
- **Passive Read-Only**: All it does is open a standard text file (`EE.log` generated by the game) and read new lines as they appear. To the game's anti-cheat, this is no different than opening the log file in Notepad.
- **Standard Overlay**: The overlay is a standard Windows UI element made transparent. It does not hook into DirectX or the game engine.

## Installation & Usage

You have two options to run this tracker: download the ready-to-use application, or build it yourself from the source code.

### Option A: Quick Start (Download `.exe`)
If you just want to use the tracker without installing any programming tools, this is the easiest way:
1. Navigate to the `dist` folder in this repository and download `SoulframeTracker.exe`.
2. Run the `.exe` file before or during a Soulframe session.
3. Enter a dungeon and the overlay will appear in the top-left corner.
4. Wait for the "Found!" text and beep sound when an Arena spawns.
5. To close the program, right-click the green system tray icon and select "Exit Tracker", or press `Ctrl+Shift+Q`.

### Option B: Compiling from source (for beginners)
If you prefer to verify the code and build the `.exe` file yourself, follow these simple steps:

1. **Install Python**: Download and install [Python](https://www.python.org/downloads/). During installation, make sure to check the box that says **"Add Python to PATH"**.
2. **Download this code**: Click the green "Code" button at the top of this GitHub page and select "Download ZIP". Extract the folder to your computer.
3. **Open Command Prompt**: Open the extracted folder, click on the address bar at the top of the file explorer, type `cmd`, and press **Enter**. This will open a black command window.
4. **Install required libraries**: Copy the following command, paste it into the command window, and press Enter:
   ```cmd
   pip install pystray pillow pyinstaller
   ```
5. **Compile the program**: Finally, copy and paste this command and press Enter:
   ```cmd
   pyinstaller --noconsole --onefile --name "SoulframeTracker" monitor.py
   ```
6. **Find your `.exe`**: Once it finishes, a new folder named `dist` will appear. Inside it, you will find your newly built `SoulframeTracker.exe`!
